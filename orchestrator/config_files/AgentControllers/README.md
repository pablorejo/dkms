# Agent Controller Config Templates

## Purpose

This folder contains baseline agent-controller JSON files such as `1.json`,
`2.json`, and so on.

## What the files are used for

- deployment flows that instantiate agent-controller endpoints
- DKMS-side control and status APIs used by some orchestration paths
