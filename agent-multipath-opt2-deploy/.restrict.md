  6. Si por error introduzco un parámetro fuera del rango permitido → revertir inmediatamente y registrar.

  **Estado terminal nuevo añadido:** `BLOQUEADO_AUTOTUNE_AGOTADO` (similar a `BLOQUEADO_CRITERIOS_NO_CUMPLIDOS` pero después de 3 intentos válidos de auto-tune).
